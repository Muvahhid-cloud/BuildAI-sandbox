# Material assets (textures and HDRI)

Third-party image assets used by the 3D viewer. Only **CC0** assets from
[ambientCG](https://ambientcg.com) and [Poly Haven](https://polyhaven.com) are allowed
(decision 2026-10-31, "V1 Visual quality"). About 1K resolution; the whole folder stays under
~40 MB.

- Files live in `data/materials/textures/<slot>/{albedo,normal,roughness}.jpg` and
  `data/materials/hdri/`. The material library (`library.json`) references them by these paths
  together with the real-world tile size (`tile_size_m`).
- Normal maps are **OpenGL** convention (ambientCG `NormalGL`, Poly Haven `nor_gl`).
- The web app serves copies from `apps/web/public/materials/` (generated by
  `scripts/sync-materials.mjs` on `pnpm dev` / `pnpm build`, git-ignored).
- A slot marked **TODO** has no files yet: the renderer falls back to the library's flat color.
  To add it, download the 1K JPG set, rename the maps to `albedo.jpg`, `normal.jpg`,
  `roughness.jpg`, put them in the slot folder, fill in the row and remove the TODO.

## HDRI (environment lighting)

Used for image-based lighting and reflections only (the visible sky is a neutral gradient). The
`park` HDRI (Poly Haven "Rooitou Park") from the same package was tried first and rejected: its
average colour is strongly blue (mean linear RGB ≈ 0.20 / 0.26 / 0.74) and tinted every surface.
