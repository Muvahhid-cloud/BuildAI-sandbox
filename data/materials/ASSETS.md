# Material assets (textures and HDRI)

Third-party image assets used by the 3D viewer. Only **CC0** assets from
[ambientCG](https://ambientcg.com) and [Poly Haven](https://polyhaven.com) are allowed
(decision 2026-10-31, "V1 Visual quality"). About 1K resolution; the whole folder stays under
~40 MB (now ≈ 17.3 MB: textures 15.7 MB, HDRI 1.5 MB).

- Files live in `data/materials/textures/<slot>/{albedo,normal,roughness}.jpg` and
  `data/materials/hdri/`. The material library (`library.json`) references them by these paths
  together with the real-world tile size (`tile_size_m`), taken from the asset's published
  dimensions.
- Normal maps are **OpenGL** convention (Poly Haven `nor_gl`, ambientCG `NormalGL`).
- Files are the unmodified 1K JPG downloads, renamed: Poly Haven `<id>_diff_1k.jpg` → `albedo.jpg`,
  `<id>_nor_gl_1k.jpg` → `normal.jpg`, `<id>_rough_1k.jpg` → `roughness.jpg`.
- The web app serves copies from `apps/web/public/materials/` (generated by
  `scripts/sync-materials.mjs` on `pnpm dev` / `pnpm build`, git-ignored).
- A slot without files falls back to the library's flat color. To add or replace one, download
  the 1K JPG set, rename the maps as above, update `tile_size_m` and the row below.
- All current assets are from Poly Haven: ambientCG's downloads are served from
  `acg-download.struffelproductions.com`, which the build environment does not allow.
